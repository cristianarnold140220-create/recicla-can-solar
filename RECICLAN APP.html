Voltaje Lógico: 5V DC • Fuente Primaria: 12V 4.5Ah + LM2596
1. Sensores de Entrada

Detección ultrasónica HC-SR04 de alta precisión mediante cálculo de tiempo de vuelo pulseln().

Pin D7: TRIG Sensor 1 (Botellas)
Pin D6: ECHO Sensor 1 (Botellas)
Pin D3: TRIG Sensor 2 (Perrito)
Pin D2: ECHO Sensor 2 (Perrito)
2. Control & Pantalla

Microcontrolador ATmega328P con comunicación serial I2C hacia display LCD 16×2 y diagnóstico LED.

Pin A4: SDA (Línea de datos I2C)
Pin A5: SCL (Línea de reloj I2C)
Pin D12: LED Rojo (0/5 botellas)
Pin D11: LED Amarillo (1 a 4 botellas)
Pin D10: LED Verde (Meta 5 alcanzada)
3. Actuadores & Potencia

Servomotor metálico MG996R gobernado por PWM y circuito acústico piezoeléctrico de señalización.

Pin D9: Servomotor MG996R (PWM)
Pin D8: Buzzer Activo 5V
Step-Down LM2596: 12V Batería → 5V VCC
Regulador PWM: Panel Solar 10W → Batería

#include <Wire.h>
#include <LiquidCrystal_I2C.h>
#include <Servo.h>

const byte LED_ROJO = 12;
const byte LED_AMARILLO = 11;
const byte LED_VERDE = 10;
const byte PIN_BUZZER = 8;
const byte PIN_SERVO = 9;

const byte TRIG_BOTELLAS = 7;
const byte ECHO_BOTELLAS = 6;
const byte TRIG_PERRITO = 3;
const byte ECHO_PERRITO = 2;

const int META_BOTELLAS = 5;
const float DISTANCIA_BOTELLA = 15.0; // cm
const float DISTANCIA_PERRITO = 20.0; // cm
const unsigned long TIEMPO_DISPENSADO = 5000; // 5 segundos

LiquidCrystal_I2C lcd(0x27, 16, 2);
Servo servoReciclaCan;

int botellas = 0;
bool recompensaDisponible = false;
bool dispensando = false;

float medirDistancia(byte pinTrig, byte pinEcho) {
  digitalWrite(pinTrig, LOW);
  delayMicroseconds(3);
  digitalWrite(pinTrig, HIGH);
  delayMicroseconds(10);
  digitalWrite(pinTrig, LOW);
  unsigned long duracion = pulseIn(pinEcho, HIGH, 30000UL);
  if (duracion == 0) return -1.0;
  return duracion * 0.0343 / 2.0;
}

void setup() {
  Serial.begin(9600);
  pinMode(LED_ROJO, OUTPUT);
  pinMode(LED_AMARILLO, OUTPUT);
  pinMode(LED_VERDE, OUTPUT);
  pinMode(PIN_BUZZER, OUTPUT);
  servoReciclaCan.attach(PIN_SERVO);
  servoReciclaCan.write(0);
  lcd.init();
  lcd.backlight();
  lcd.print("RECICLA-CAN");
  lcd.setCursor(0, 1);
  lcd.print("Iniciando...");
}

Proyecto de Investigación: RECICLA-CAN SOLAR

Diseño, Automatización & Pruebas: Elaborado por: Damarish Yonsu Ch. C.

El sistema RECICLA-CAN SOLAR valida de manera integral la convergencia de la automatización mecatrónica con el desarrollo socio-ambiental sostenible. Al canalizar incentivos inmediatos en alimento canino por cada ciclo de 5 botellas PET recicladas, y sostener su régimen de operación con un sistema fotovoltaico aislado de 10W y 12V, el proyecto sienta las bases de un mobiliario urbano inteligente y de alta resiliencia.
